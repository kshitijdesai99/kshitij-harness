# Release notes: 2026-10-25

User-facing changes in kh.

## Feature visibility

- Added `features/` with a concise index of capabilities, their introduction dates, and subsequent developments. Each feature has a separate page for its purpose, current behavior, limitations, evidence, and dated history.
- Linked the feature index from the README; each feature page owns its operating details and history instead of accumulating them in the index.
- Added a maintenance guide for new features, meaningful updates, splits, replacements, and retirement.
- Consolidated operating instructions and design explanations into their owning feature pages and removed the separate `manual/` tree. The feature catalog is now the single project reference, with shared architecture/development guides and documentation ownership rules.
- Added `AGENTS.md` as a repository entry point linking to setup, feature pages, architecture, development conventions, and documentation maintenance instead of copying them.

## Input isolation

- Peer-agent messages are delivered independently of the human input editor. An incoming report does not append to, submit, or alter an unfinished draft; the user submits it with Enter.
- Peer delivery bypasses input history, multiline/paste content, and command/approval parsing. Updated senders refuse receivers without live isolated-input support rather than injecting text into their drafts. Restart existing sender and receiver chats onto the new build.
