# Release notes: 2026-11-07

## Bounded local plugin hooks

- Local plugins can use an explicitly trusted [bounded hook subset](../features/project-configuration.md#plugin-hooks): `SessionStart`, `UserPromptSubmit`, `PreToolUse`, `Stop`, and `SessionEnd`. `Stop` permits at most one continuation; this is not full Claude Code parity.
- Plugin enablement is not execution trust. Hooks can mutate files and Git hooks, launch detached processes, or invoke external recorders/sync; timeouts limit waiting, not those effects.
- Hook context uses JSON-quoted untrusted payloads with plugin/event provenance, not executable instructions or approval. Skills named in ordinary hook prose load on demand through existing capability discovery; there is no plugin-specific slash adapter, Markdown execution, or preferred plugin root for generic Bash. Each hook keeps its own plugin root, while explicit tool commands use discovered paths and normal approval.
- Hooks receive a separate private projection of actual users and completed assistant replies, excluding worker assignments and peer messages, without rewriting resumable history. Projections use a kh-only namespace under the actual Claude configuration, preserving external recorder authentication; existing private projections are preserved on session reopen without copying credentials. Cogit requires Node.js 22.13 or newer; Markdown references do not become executable commands.
