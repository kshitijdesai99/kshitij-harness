# Release notes: 2026-11-11

## Worker-independent visual companions

- Managed [Marimo companions](../features/visual-companion.md#ownership-and-storage) now belong to the root chat process, including servers launched by workers. Completing or closing a worker pane no longer stops its ready servers; the root and its workers share listing and explicit stop controls.
- Closing the root chat still stops its managed servers, including after abrupt root-process exit. Startup cancellation or a worker dying before startup finishes does not transfer a partially started server. Unrelated sessions and standalone servers remain isolated; notebooks and logs are retained.
- [Restart existing chats](../features/startup-rebuild.md#restart-onto-a-new-build) to use the new lifecycle. A restart still ends the old root process and stops its servers; start the retained notebook again afterward for a fresh authenticated URL.

## Bounded memory hierarchy

- [Critical memory](../features/keyword-recall.md#core-critical-contextual-and-history) is considered before contextual retrieval, within the existing total allowance. Exact selected notes, a fresh whole contextual synopsis, and visible overflow improve coverage without changing instruction authority or guaranteeing model compliance.
- [Importance and absolute expiry](../features/memory-controls.md) are versioned metadata. `kh memory remember` supports `--importance normal|critical` and `--expires RFC3339|none`; ordinary updates preserve omitted metadata, and expired knowledge stays inspectable in history.
- [Background learning](../features/learning-queue.md) classifies durable notes and eligible legacy user-provenance notes; whole-source fingerprints prevent stale contextual summaries from being injected.
- The top eligible [database procedure](../features/procedure-loading.md) loads its whole inert body and compact provenance automatically only when they fit; assets remain explicit-load only. Project skills still use model-selected discovery; no general task router or automatic script execution was added.
- [Persistent note IDs](../features/memory-history.md) no longer reuse purged IDs in new-code writes. Restart all writers: already-running old binaries can still reuse IDs, and identity reuse predating migration cannot be repaired retroactively.
- [Host-origin markers](../features/learning-origin.md#host-memory-provenance) protect seen tracking from memory-looking user/tool text, while staying private to saved provider history.
- The default total remains 500 estimated tokens. `critical_memory_max_tokens: 0` automatically reserves half of the normalized total; negative disables only critical packing. Admission limits do not bound the whole saved conversation. [Restart onto the new build](../features/startup-rebuild.md#restart-onto-a-new-build) to update existing chats.
