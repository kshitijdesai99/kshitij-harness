# Release notes: 2026-11-10

## Memory policy and diagnostics

- The short [runtime memory policy](../features/project-configuration.md#runtime-memory-policy) is appended even with a saved custom system prompt, for fresh/resumed chats and assigned workers. This verifies instruction delivery, not model compliance.
- Native memory `explain` and `kh memory explain "QUERY"` provide [content-free stage counts](../features/retrieval-diagnostics.md); ordinary search still returns notes. CLI explain distinguishes requested hybrid mode from effective pipeline configuration. In-chat recall diagnostics identify loaded memories by ID rather than key.
- These changes do not replace the memory engine, schema or extractor. A current explanation cannot establish the cause of a historical miss without that turn's trace. [Restart onto the new build](../features/startup-rebuild.md#restart-onto-a-new-build) to update a running chat.
