# Release notes: 2026-11-03

User-facing changes in kh.

## Avoid duplicate manager exploration

- [Manager coordination policy](../features/native-agents.md#duplicate-manager-exploration) now delegates substantial investigation and source/document exploration as well as execution. Once delegated, managers use concise worker conclusions and targeted follow-ups before reading directly, rather than repeating broad exploration.
- Initial scoping, ordinary informational answers and narrow reads for specific missing evidence, conflicts or verification remain allowed. Workers return conclusions, exact references, checks and uncertainty instead of raw history or bulk source. Root/resume instructions, native promotion reminders, the discoverable agents contract and repository guidance are aligned; this is instruction delivery, not a deterministic compliance guarantee or hard read restriction.

## On-demand hosted web search

- The CLI keeps configured [hosted web search](../features/web-search.md) available without adding its schema to every fresh request. Discover and describe `enable_web_search`, then invoke it with `arguments: {}`; activation performs no search itself and exposes hosted search/open/find on the next provider step. `web_search: false` registers no activation tool. Existing direct Codex `New` callers retain eager compatibility.
- Historical hosted calls retain the schema needed for provider validation when search is permitted. Disabled search with hosted-call history explicitly requires `/compact`; compaction uses only the necessary hosted schema with `tool_choice: "none"`, not executable search. Request construction and cache keys share one effective-tool snapshot.
- [Compact context](../features/project-configuration.md#compact-context-and-tool-discovery) still loads contracts and catalogs on demand; this does not restore eager schemas. Roughly 5,000 tokens remains a fresh-session baseline target, not a history hard cap. An identical-prompt comparison reported [2,239 input tokens without hosted search versus 6,703 with it](../features/turn-metrics.md), with zero tool calls. A subsequent fresh full CLI greeting with the unchanged real-HOME configuration exited successfully at **2.3k input tokens** (rounded to 0.1k), with zero tool or hosted-search actions; this is a separate measurement.
