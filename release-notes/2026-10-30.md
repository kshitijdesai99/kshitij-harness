# Release notes: 2026-10-30

User-facing changes in kh.

## Saved sessions

- `kh sessions` now lists every saved chat in the current folder, including subagents, with `[main]`, `[subagent: name]` or `[unknown]` in the preview.
- New chats save their identity; resume keeps it unchanged. Older chats remain unknown, and `/new` and `/fork` create main chats, even from a worker. IDs and previews still fit the terminal width.

## Project configuration

- Added [`.agents`/`.agent`/`.claude` configuration](../features/project-configuration.md) from home and startup ancestors, including outside Git repositories. More specific locations win; at the same location, `.agents` wins over `.agent`, which wins over `.claude`.
- Core instructions and unscoped rules provide startup context. Skills, commands, and supporting files use compact metadata and on-demand loading through `project_capability`; slash invocation loads the selected body with arguments. Reading script content never runs it. Scoped rules are diagnosed rather than applied without their scope.
- Added a supported local plugin subset with namespaced skills, commands, and MCP declarations. Remote plugin discovery and installation are not supported.
- MCP stdio and Streamable HTTP servers provide real tools plus lazy resources, resource templates, and prompts when advertised. Startup trust and per-call approval respect auto mode. Server effects are **not confined by the OS Bash sandbox**; review definitions before trusting them.
- Startup configuration diagnostics are summarised in one line; `/project diagnostics` shows the full list. Trash and root runtime metadata are excluded. Unsupported hooks, permissions, and settings are diagnosed rather than silently executed. Home JSON credentials/environment values stay out of prompt context. Restart kh to reread startup configuration.
