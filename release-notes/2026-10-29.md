# Release notes: 2026-10-29

User-facing changes in kh.

## Visual companion

- Added an optional marimo learning-rate example, followed by native `visual` actions to create notebooks and start, list, or stop session-owned servers. URLs are returned without opening browser tabs.
- Moved generated notebooks, logs, and runtime state outside the repository, with a shared dependency cache. Only owned servers stop on actual kh process exit—not on tmux detach or later turn cancellation—and artifacts are retained. A guardian handles abrupt owner exit, including SIGKILL, within the [documented process-group boundary](../features/visual-companion.md#ownership-and-storage).
- Native launches provision PEP 723 dependencies with `uv run --with-requirements`, then use `marimo run --watch --no-sandbox` to render immediately, watch file edits, and prevent server detachment from the guardian. This marimo environment-launcher setting does not disable kh's OS Bash sandbox or existing approvals.
- Standalone manual launches remain unmanaged. This is lifecycle management, not chat synchronization or browser navigation. See the [capability guide](../features/visual-companion.md) for current usage, ownership boundaries, evidence, and history.
