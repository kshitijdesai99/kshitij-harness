# Release notes: 2026-10-29

User-facing changes in kh.

## Standalone visual companion

- Added an optional marimo example for exploring gradient descent with a learning-rate slider, reactive plots, and an explanation. It runs independently in a browser, not inside kh.
- Added the [canonical capability guide](../features/visual-companion.md) and feature-index entry, covering launch instructions, requirements, limitations, evidence, and initial history. Local runtime state and caches remain under the example's ignored `.runtime/` directory.
- This initial shipping change does not implement kh runtime integration, chat synchronization, or page navigation.
