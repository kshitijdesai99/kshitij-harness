# Release notes: 2026-11-06

## Assistant reply spacing

- [Final Markdown replies](../features/markdown.md) now have two columns of breathing room on each side in capable terminals, including session replay. Wrapping reserves the right columns without appending padding spaces; long code lines remain complete, and very narrow terminals prioritize content.
- Prompts, tool output, commentary, redirected output, and `TERM=dumb` keep their existing layout.

## Harness feedback and worker conclusions

- [Routine harness output](../features/terminal-feedback.md#subdued-harness-output) uses the existing muted, non-bold gray; worker-result blocks and peer messages retain subdued amber/brown. Human queries use blue in live output and replay, and assigned-task banners use bold green. Main replies, warnings and approval prompts remain unchanged.
- Parents display [new direct-child conclusions](../features/native-agents.md#visible-worker-results) as always-visible original Task + Result pairs in one draft-safe write, independently of the active model turn. Missing older tasks are labeled `Original task unavailable`; no task is reconstructed from summaries or private context. Results are bounded conclusions, not transcripts, and do not automatically enter model context. Restart/resume skips old publications; this is not crash-atomic exactly-once delivery.

## Canonical repository decisions

- Removed the redundant `.agents/decisions.md` ledger. Useful unique facts now live with [CLI-fixture isolation](../features/development.md#build-and-test) and the [undelivered issue-recording scope](../features/native-agents.md#duplicate-manager-exploration); existing feature pages retain their already-documented behavior and history.
- [Repository guidance](../features/CONTRIBUTING.md#repository-decisions) now records decisions on the owning feature page with an explicit `workspace.decision_path`. The generic tool default is unchanged; `.agents` guidance, configuration and inert fixtures are preserved.
