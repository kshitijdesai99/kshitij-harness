# Release notes: 2026-11-05

## Assigned task startup banner

- Native descendants now show **ASSIGNED TASK — agent name** and the full task in explicit bold cyan before activity/progress setup and model/tool work, in both headless and interactive modes.
- Long tasks wrap naturally and multiline assignments remain complete. Redirected output and color-disabled terminals stay plain; interactive descendants no longer echo a duplicate initial query. Ordinary root output is unchanged.
- This is a [startup scrollback banner](../features/terminal-feedback.md#assigned-task-startup-banner), not a pinned header. Launcher rebuilding and earlier session/memory setup can precede it.
