# Release notes: 2026-11-02

User-facing changes in kh.

## Compact startup context and on-demand tools

- [Tool discovery](../features/project-configuration.md#compact-context-and-tool-discovery) now uses `tool_registry` search/describe and `tool_invoke` rather than sending every native and MCP contract up front. Full contracts remain available on demand; invocation retains original approvals and safety checks. MCP startup trust, browser consent, and host capabilities are unchanged.
- Skills, commands, root configuration references, and historical decisions stay host-side until requested. Binding `CLAUDE.md`, `AGENTS.md`, and unscoped rules remain loaded with existing precedence; binding-budget overflow fails explicitly rather than silently evicting guidance. Default [workspace inspection](../features/project-configuration.md#target-workspaces) returns guidance, source counts, and the decision path; decision text has explicit bounded paging.
- Automatic memory injection defaults to **500 estimated tokens**, down from 4,000; [explicit saved settings remain intact](../features/keyword-recall.md). Retrieval and learning timing are unchanged.
- Roughly **5,000 tokens** is the default bootstrap design target, not a hard history cap or a measured token claim. `/project diagnostics` exposes component bytes and a bytes/4 instruction/map-floor estimate; [turn metrics](../features/turn-metrics.md) remain the source for actual provider-reported usage.
